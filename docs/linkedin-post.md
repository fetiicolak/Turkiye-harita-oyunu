# LinkedIn paylaşım metni

Türkiye'nin 81 ilini öğrenmeyi daha etkileşimli hâle getirmek için geliştirdiğim **Türkiye Harita Oyunu** yayında! 🇹🇷

Projede dört farklı oyun modu bulunuyor:

- Haritadan ili seçip adını tahmin etme
- İl isimlerini yazarak Türkiye haritasını doldurma
- Sesli söylenen ili haritada bulma
- Plaka kodlarını şehirlerle eşleştirme

Uygulama telefon, tablet ve bilgisayarda çalışıyor. PWA desteği sayesinde cihaza kurulabiliyor ve daha önce yüklenen dosyalarla çevrimdışı da kullanılabiliyor.

Teknik tarafta Vanilla JavaScript, SVG, GeoJSON, Service Worker, Web Speech API, Web Share API ve Local Storage kullandım. Masaüstü, mobil ve tablet akışlarını Playwright testleriyle kontrol ediyorum; GitHub Pages yayını testler geçmeden yapılmıyor.

🎮 Oyunu deneyin: https://fetiicolak.github.io/Turkiye-harita-oyunu/

💻 Kaynak kod: https://github.com/fetiicolak/Turkiye-harita-oyunu

Görüşlerinizi ve geliştirme önerilerinizi duymak isterim. Özellikle en çok hangi oyun modunu beğendiğinizi yorumlarda paylaşabilirsiniz.
